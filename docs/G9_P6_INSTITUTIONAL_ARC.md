# G9 P6 — Fictional institutional archive response

**Issue:** #142 · G9 semantic sandbox.

## Two materially different scales

- **District Records Office** — a generated hacker-owned target with a *real archive/records/ledger service* suffers a successful, public NPC intrusion. Its public-service records inquiry binds to **one** actual local operator group.
- **Federated Public Records Commission** — the same incident can cause a distinct *national-network*, joint records review across **two** genuinely linked rival operator organizations, not two differently named clones. The second office responds at a later 360-minute tick. This is a bounded fictional inter-office service coordination model, **not** a simulation of an actual nation, government or national economy. It has independent containment, public attention, response history, and a defense consequence read by the existing NPC-vs-NPC combat system on subsequent ticks.

Both cases use the SAME finite five action verbs. The active institution scope is selected by stable seeded hash after the incident is **actually committed**, not by the player's rank or an invented quest giver. Incident provenance binds real public outcome, source actor, target owner, organization membership and an actual archive-like service. No new network attack instructions.

## World acts before and after player input

Public NPC incident → `InstitutionalCaseOpened`. Subsequent 360-minute boundaries generate `InstitutionalResponse` receipts *from specific participating offices*, update containment/public attention, and change institutional defenders' effective defense by 5 after a documented response. For a national-network case, different participants respond at different ticks. Limits: two concurrent cases, 48 total, four office response ticks per case, finite four-day player decision period; cases expire but completed office inquiries survive. No player action is required to advance the body.

The player first maps **at least one existing valid host** using G9 P1 earned-machine fact. No secret source truth can be obtained merely by reading the UI. Choices and consequences:

| Action | Cost / value | Institutional / relationship consequence |
|---|---|---|
| Disclose | no credit | raised public attention, trust +6 / grudge +11 with source owner |
| Quiet handoff | no credit | sealed record, trust +9 / grudge +2 |
| Sell | +95 district or +180 national-network | intel market, trust -6 / grudge +19 |
| Suppress | -35 credits (must have funds) | sealed response and less attention, trust -12 / grudge +25 |
| Walk away | safe zero-cost retreat, no source reputation cost | player intervention ends; office investigation **continues** |

Effects use authoritative CommandBus, existing value ledger and causal relationship mutation. No status can be resolved twice, and the end-run gate remains absolute. Terminal `civic map|disclose|handoff|sell|suppress|walk-away <case-id>` and Underground GUI share the CommandBus. State persists in the current-run Zod save contract. GUI receives only public office scope, response phase, attention band and a host handle only once independently discovered; never the hidden owner ID, organizational graph or actor skill.

## Verification limits

Unit tests prove real-source binding, local + national-network independently participating offices, multi-tick autonomous consequence and defense, earned evidence, divergent endings, payment rejection, rank invariance, saved/replayed split waits, terminal/GUI parity, projection privacy and canonical zero-drift. Chromium desktop + 390px smoke tests remain automated, **not a human playtest**.

**Intentionally not claimed:** full country simulation or all institutional sectors; trade only moves existing in-game credits; no government policy, elections, real-world attacks or public-facing NPC inbox omniscience. Human unfamiliar-player acceptance remains **NOT RUN**.
