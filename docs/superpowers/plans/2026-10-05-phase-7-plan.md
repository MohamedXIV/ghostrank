# Phase 7 — Endings and Long-Run Systems

Issue: #25  
Dependency: Phase 6 / #24 complete.  
Platform policy: web-first; desktop/Tauri history reconciliation remains #19.

## Goal

Make survival, deciding when to stop, and leaving the underground meaningful
goals independent of reaching rank #1.

Phase 7 owns the boundary Phase 6 intentionally refused to cross: terminal
state, ending eligibility, voluntary retirement, completed-run history, veteran
pressure, and bounded late-game capability.

## Grounded starting point

At Phase 7 kickoff the repository already had:

- Phase 6 investigations, probes, physical retaliation, safehouses, compromise
  conditions, and player-safe postmortems;
- deterministic world time and one fixed ecosystem tick;
- one browser active-run save slot;
- no terminal record;
- no `RunEnded`;
- no completed-run history.

P0 established the missing terminal substrate before any eligibility policy.

## Slice order

### P0 — Terminal run contract (delivered, D037 / #41)

One `WorldState.ending` record, one idempotent `endRun`, one `RunEnded`
event, one terminal command guard, canonical persistence, safe final projection,
and an in-world final screen. P0 adds no ending trigger.

### P1 — Consequence-driven forced endings (D038)

Consume only current Phase 6 causal conditions. Identity exposure branches by
history into ARRESTED / UNMASKED / MISSING; STRANDED uses P4's explicit resource
floor; generic COMPROMISED requires same-boundary rig + dwelling loss. A
terminal boundary freezes the current world-time command immediately.

### P2 — Exit plan as a playable operation

Retirement is a multi-step world-time process, not a menu button. Reuse existing
fictionalized obligations, relationships, infrastructure, location, and cooling
vocabulary. Do not add real-world evasion procedures.

### P3 — Retirement outcomes and VANISHED

Derive retirement variants from actual run history/context, never from a
single morality meter or the starting White/Black package. The rare peaceful
White VANISHED ending requires a coherent history; Black retirement can succeed
with materially different tone.

### P4 — Completed-run history

Extend persistence so completed final states are archived and browsable. Store
authoritative final truth once; derive summary/postmortem presentation from it.
Closed PR #40 is a reference for IndexedDB v2 history and atomic active→archive
movement, but its competing `run.status` terminal model is superseded by D037
and must not be restored.

### P5 — Exceptional long-run pressure

Make unusually long survival harder because accumulated causal world history
creates more obligations, exposure, grudges, attention, and infrastructure
pressure — never because rank becomes combat power.

### P6 — Limited exotic / quantum capability

Late, rare, bounded content using the existing capability model. It must not
erase ordinary constraints or become a mandatory rank ladder / universal
success button.

## Global invariants

- rank is reputation/visibility, never ending power;
- one run ends at most once;
- every ending cites authoritative causal provenance;
- commands cannot mutate a terminal run;
- if an ending happens inside a time command, the clock stops at that exact
  ending boundary and no later same-tick/tail work runs;
- ending presentation cannot leak hidden truth beyond the established
  player-safe epistemic boundary;
- completed history derives summaries from final authoritative state rather than
  duplicated mutable counters;
- legacy saves remain valid under explicit compatibility rules;
- browser is the normal gameplay release gate;
- no real networking, exploit execution, host-code execution, credential theft,
  or real-world evasion procedures.

## Phase exit criteria

- surviving and leaving is meaningful without reaching rank #1;
- multiple forced endings arise from deterministic causal history;
- voluntary retirement is a playable process;
- a rare peaceful White VANISHED path exists;
- Black retirement can succeed with distinct context/tone;
- completed runs remain browsable with safe postmortem context;
- long survival becomes harder for causal reasons;
- exotic capability remains late and bounded.
